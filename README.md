# japanese-a1
Self-study Japanese A1 course — 18 units with vocabulary, grammar, dialogues and exercises in romaji, kana or kana + kanji. Includes a vocabulary recap after every unit, mixed-exercise checkpoints every 3 units plus a final checkpoint, and progress saved in the browser's database (IndexedDB).

Pages: `index.html` (A1 course), `kanji.html` (N5 kanji lessons), `kana.html` (hiragana & katakana lessons with reading/writing drills, writing pad and speed round).
